# Проверка UI в браузере и Electron

Дата: 27 ноября 2026 года. Проверена текущая рабочая версия этапов 0–12b: настоящее приложение запускалось в Chrome и отдельном процессе Electron на macOS. Найдены и исправлены два дефекта интерфейса. Это сценарная проверка основных пользовательских потоков, а не полная аттестация всех интеграций и платформ.

## Стенд

Отдельный API на `localhost:53019`, disposable PostgreSQL database, S3, настоящие chat/workspace workers и собранный web frontend. Рабочий экземпляр на порту 53009 не изменялся. Использовались только синтетические учётная запись, беседы и файлы.

Desktop запускался на официальном Electron 45.3.0 из локального кеша, с текущим `apps/desktop/src/main.cjs`, preload и отдельным временным профилем. Проверен вход через браузер с привязкой устройства. Установленное пользовательское приложение не подменялось. Подписанный дистрибутив, установщик и обновление приложения не проверялись.

Для воспроизводимости конфликтов и неизвестного исхода файловый executor был тестовым, в памяти. API, очередь, workers, журнал и хранилище revisions работали реально. Сценарий `safe-desktop` означает применение через интерфейс Electron к серверному тестовому executor, а не запись в реальную файловую систему desktop. Исследовательские записи и исходные планы подготовлены fixtures. Для streaming/очереди использован локальный управляемый провайдер с настоящим выполнением запроса через runtime.

## Исправления

1. **Обрезание обзора изменений.** Пользовательская ширина внутреннего контейнера 1120 px конфликтовала с ограничением Gravity Dialog в 900 px. Удалены класс `run-changes-dialog` и правило ширины; размер задаётся документированными `fullWidth`/`maxWidth`. После исправления измерено 900/900 px на широком экране и 350/350 px на узком. Повторно проверено в Chrome и Electron.
2. **Ложная ошибка после Stop.** Отменённая попытка с техническим `RUN_FINISHED` отображала общую ошибку с предложением повторить запрос. `GenerationActivity` теперь использует существующее локализованное сообщение `RUN_CANCELLED` для отменённой попытки. Добавлены два regression-теста RU/EN; реальный браузер после Stop показывает «Ответ остановлен.».

## Автоматическая регрессия

После обеих правок полный `npm run check` завершился с кодом 0: границы пакетов, форматирование, типы, сборки server/web/Electron frontend, **124 unit-теста**, **226 UI-тестов в 34 файлах**, лицензии **781** пакета. `git diff --check` проверяется отдельно. Сообщения jsdom о не реализованном `scrollTo` не привели к падению тестов; реальная прокрутка дополнительно проверена в запущенном приложении.

Полный backend integration suite в этой проверке повторно не запускался. Предыдущие **306 passed / 6 skipped** относятся к [поставке применения 12b](zcode-rollback-apply-results.md); эти шесть инфраструктурных сценариев здесь не закрыты. Live UI использовал настоящие API/worker/БД и отдельно сверенные журналы, но тестовый файловый executor.

## Доказательства и границы

Локальные артефакты находятся в ignored `work/zcode/ui-smoke/`:

- `check-final.log` — итоговая регрессия после обеих правок;
- `backend-observations.json`, `backend-observations-summary.json` — сверка журналов и очереди через API;
- `desktop-rollback-light-en.png` — успешное применение в Electron после исправления ширины;
- `web-narrow-partial.png` — частичный результат при ширине браузера 390 px;
- `web-partial.png`, `desktop-narrow-diff.png`, `web-queue-completed.png` — дополнительные состояния UI.

Снимки `web-rollback-completed.png` и `web-conflict.png` сделаны до исправления ширины и не являются доказательством итоговой геометрии.

Не проверялись реальные OS-записи отката, PTY/контейнерные интеграции, аварийное восстановление worker через UI, новое выполнение и отмена исследователя, вызов `read_batch`, ручное сжатие, производительность реального браузера на 1000 сообщениях, screen reader, Windows/Linux и качество/стоимость внешних моделей. Они не считаются пройденными благодаря компонентным тестам. Пилотные флаги в пользовательской конфигурации не включались.

Тестовый Electron закрыт. Из-за потери соединения с автоматизацией четыре старые тестовые вкладки Chrome не удалось закрыть автоматически; они относятся только к остановленному локальному стенду.
