Pinned MCP schemas and conversation content now share the selected model's token
budget instead of fixed 50,000/120,000-character limits. The output allowance and
protocol overhead are reserved; requests are checked again after tool results grow.

Model settings now expose **Model context tokens** separately from **Maximum output
tokens**, including local model aliases. Unknown windows default to 131,072 tokens;
unknown output limits default to at most 8,192 tokens. Set the actual context for local
aliases. Counts use local BPE; unsupported model tokenizers use a conservative estimate.
Submission errors report estimated input and the available budget. See docs/chat.md.

No new database migration is required when upgrading from alpha.8. Back up your data
and existing `.env`, preserve encryption keys, replace only `compose.yaml`, then run
`docker compose pull` and `docker compose up -d --wait --wait-timeout 180`. Update or
remove any `RUNOZA_IMAGE` override. Refresh the web app; desktop users should install
the matching bundle to edit the new context setting.
