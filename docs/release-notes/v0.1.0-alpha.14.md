This prerelease fixes premature agent termination and the crowded chat layout
reported after alpha.13.

The default model-call ceiling is now disabled (`max_agent_steps=0`). Explicit
positive administrator limits still apply, including the corresponding tool-call
budget. Cancellation, live permissions, recovery ceilings, repeated-action guards
and existing run deadlines remain in force. MCP discovery returns short search
previews; exact tool schemas remain available. Agent instructions emphasize reusing
collected evidence, updating plan progress and completing the requested analysis.

Migration 046 changes the settings/defaults to zero, including stored settings equal
to the former default of 64. Other positive settings and all existing run snapshots
are preserved. Previously interrupted runs are not restarted automatically. The
"Continue task" action starts a new run on the existing conversation branch and
preserves the current draft; it does not replay the previous run's tool journal.

Plans appear once in the scrollable history and start collapsed. Consecutive tools
and interleaved reasoning form collapsible action groups; MCP calls show tool names.
Pending approvals and unknown outcomes stay visible. Finished-run diagnostics are
collapsed in history, while the composer shows only compact active status. Context
and the follow-up queue open in dialogs. Uncertain submission receipts open the
queue for reconciliation. An explicit Execute / Plan only choice replaces the
ambiguous planning checkbox. Existing plan acceptance, change review, rollback,
branching and permission controls remain available.

Back up PostgreSQL, object storage, workspaces, compose.yaml and .env before upgrading.
Keep the existing environment and encryption keys; use the release Compose asset
and its pinned image digest. Do not run an older application against schema 046.
Optional research, read batching, model recovery and rollback pilots keep their
existing defaults. Desktop packages remain unsigned previews without notarization
or automatic updates.
