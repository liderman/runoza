Long conversations now allow 180 seconds for each model HTTP request instead of
30 seconds. Automatic compaction keeps a smaller working context and processes
large histories in bounded chunks. Original messages and tool evidence remain
available. Empty failed retries retain the provider error; the UI no longer
claims a partial answer exists when none was received. Confirmed model boundaries
can still recover after connection failures or transient provider errors without
repeating completed tools.

Intermediate progress, reasoning and tool calls share one collapsible work group.
Approving an action keeps the group collapsed and preserves keyboard focus and
the draft. Long user requests can be expanded, composer controls wrap within
narrow chat panes, and run diagnostics contain the change-review entry point.
MCP action details hide endpoint credentials while retaining the tool arguments.

Agent instructions require checking entity identity, units, timestamps and exact
failure conditions before drawing audit conclusions. Historical snapshots are
distinguished from current readings; unsupported causes and forecasts must be
qualified or withdrawn. Unfamiliar MCP tools require schema inspection, and
continuations must use the current run's plan version.

There are no database migrations in this release; schema 046 remains current.
Keep the existing environment, encryption keys and volumes when replacing the
release Compose file. Existing permissions, optional pilots and explicit budgets
remain unchanged. Desktop packages remain unsigned previews without notarization
or automatic updates.
