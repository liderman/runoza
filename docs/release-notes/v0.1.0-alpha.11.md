Tool responses above 50,000 characters are now saved completely in persistent
conversation files. The model receives a path, size and hash instead of a truncated
body. One result boundary applies to MCP, commands, discovery, skills and file tools.

Built-in files_list/read/search/create/write/delete tools work without code execution.
Read selected pages or search bounded excerpts, including in large single-line JSON.
files_export copies a saved response into the code workspace through the existing
approval policy, enabling grep/jq. Workspace read_file also supports pagination.
Original action results remain in the journal; context reconstruction uses file
references. Previously truncated MCP replies cannot be recovered retroactively.

Migration 037_agent_files adds scratch file storage and bounded context projections.
Back up PostgreSQL, files, compose.yaml and .env before upgrading. Preserve .env and
encryption keys; replace compose.yaml with this release asset and run docker compose
pull followed by docker compose up -d --wait --wait-timeout 180.
See docs/tool-result-files.md for quotas, permissions, offsets and validation.
