Server commands and interactive terminals now work with the standard Compose installation,
using the published Open Terminal image. Each organization/user pair has a permanent account;
each conversation has its own persistent folder. This shared container is intended for a trusted
organization and does not provide isolation against hostile code.

Installation requires only the release's `compose.yaml` and `env.example` (saved as `.env`).
No source archive, host Node.js, or terminal pool manager is required. The terminal API key is
created automatically in a persistent volume. File tools, artifacts, PTY sessions and stdio MCP
use the selected conversation folder. Files survive workspace closure and container recreation.

Upgrading from alpha.6 applies migration `034_shared_terminal`. Back up the database, files,
volumes and existing `.env` before upgrading; preserve encryption keys. For later backups,
include the new `terminal-home` and `terminal-key` volumes alongside the database and object
storage. Enable code execution in organization settings to use server commands. Existing users
of the optional isolated pool can retain their overlay and operator workflow.
