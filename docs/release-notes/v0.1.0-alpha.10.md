Runóza now compacts context automatically before the selected model's input budget
runs out, including inside long MCP tasks. `/compaction` triggers the same operation
manually; optional text focuses the summary. During an active run it waits for a
safe point after tools complete.

Structured checkpoints preserve the latest request, recent messages, tool-call
boundaries and fixed instructions. Original history stays in the database. Agents
can retrieve saved action results with `history_read` without repeating actions.
Empty, truncated, cancelled or ineffective summaries are not applied. Checkpoints
are scoped to their owner and source branch. See docs/compaction.md for the OpenCode
and Pi research, design choices and reproducible synthetic quality evaluation.

Migration 036_compaction adds checkpoint/request storage and run status fields.
Back up the database, files, compose.yaml and .env before upgrading. Preserve .env
and encryption keys; replace compose.yaml with this release asset, then run
`docker compose pull` and `docker compose up -d --wait --wait-timeout 180`.
Install the matching desktop bundle for command autocomplete and compaction status.
Plain `/compaction` submissions from older clients work when the conversation is idle.
